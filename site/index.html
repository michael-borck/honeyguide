Why Honeyguide

Retrieval is a commodity. Judgement support isn't.

Perplexity, NotebookLM, Elicit and Consensus already turn topics into sources. Honeyguide is built for the part that happens after retrieval — the part a lecturer actually spends time on.

✅

Verified, never generated

Every link is resolved and every DOI validated against Crossref, Semantic Scholar and OpenAlex. Paywalled is distinguished from dead. A hallucinated citation is impossible by construction, because nothing is generated — only retrieved and checked.

🏛️

Institutional plumbing

Licensing status (OER, Creative Commons, library-subscription), accessibility notes like captions and tagged PDFs, and LMS-ready export. The admin work you'd otherwise do by hand.

🎓

Pedagogical framing

A rationale per suggestion — why this one, what it adds, what it doesn't cover. Source-type labels (peer-reviewed, practitioner, vendor, journalism, government) and a commercially-interested flag on consultant material, which is itself a teaching moment.

🌏

Deliberately diverse results

Balanced by format and voice on purpose: one video, one paper, one practitioner piece, an explicit pass for non-Anglo sources — not five similar US blog posts. The retrieval layer's biases shouldn't become your reading list's biases.

👀

Visual triage

Thumbnails for every result so you can spot the cookie wall, the login gate, the parked domain and the SEO farm at a glance — before you click.

🔓

Yours to run

Open source, MIT licensed. Run it hosted, in Docker on your own server, or as a desktop app with a fully local LLM via Ollama — your teaching content never has to leave your machine.

Run it yourself

Self-host in one command

The Docker image is the exact build the hosted service runs: web UI and server in one container. Bring-your-own API keys are never stored server-side — browser storage only, passed per request.

# Quick start
docker run -p 3000:3000 ghcr.io/michael-borck/honeyguide:latest

# Or the full stack — just two files, no source checkout:
mkdir honeyguide && cd honeyguide
curl -fsSLO https://raw.githubusercontent.com/michael-borck/honeyguide/main/docker-compose.yml
curl -fsSL -o .env https://raw.githubusercontent.com/michael-borck/honeyguide/main/.env.example
docker compose up -d
